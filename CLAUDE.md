# Obod Maskan 3D

Turar-joy majmuasi uchun 3D savdo ilovasi (React 19 + three.js **WebGPU** + esbuild, TypeScript). Egasi: Abdulaziz. **Muloqot o'zbek tilida.** Ilova faqat kompyuterlar uchun (mobil kerak emas).

## Buyruqlar
- `npm install`
- `npm run dev` — `dist/` ni yig'adi va http://localhost:5173 da ochadi (hot reload yo'q: o'zgarishdan keyin qayta ishga tushiring)
- `node build.mjs` — `dist/` (BASIC) va `dist-pro/` (PRO); `node build.mjs light` — faqat `dist/`
- `npm run typecheck` — `tsc --noEmit`
- Deploy: `dist/` ichidagi fayllar sayt ildizida turishi kerak (Vercel: papkaning o'zi emas, ichidagilari). `file://` orqali ochilmaydi.
- Vercel (2026-11-15): loyiha `obod-maskan-3d` (aoqilov), https://obod-maskan-3d.vercel.app — `node build.mjs light; copy vercel.json dist\; vercel deploy dist --prod --yes --project obod-maskan-3d` (build `dist/` ni o'chirib yaratadi, shuning uchun vercel.json har safar ko'chiriladi). `app.js`/`app.css` 1 kun keshlanadi (vercel.json), `index.html` har safar — build index.html'ga `?v=<sha1>` qo'yadi; busiz egasida yangi sahifa + kechagi kod bo'lib, yuklanish bulutlari ochilmay qolgan edi (2026-11-15). Zaxira: kod kelmasa/eskisi kelsa (`window.__ldApp` yo'q) bulutlar DOMContentLoaded'da, baribir 90 s da o'zi ochiladi. Saytni mehmon kabi tekshirish: `node tools/prodprobe.mjs [url] [basic|pro]`
